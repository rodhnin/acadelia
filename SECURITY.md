# Seguridad en Acadelia

Gracias por ayudarnos a mantener este proyecto seguro. **No reportes vulnerabilidades en issues públicos.**

## 📬 Cómo reportar

-   Enviar reporte a: **acadelia.system@gmail.com** (o abre un hilo privado en Discussions si necesitas coordinación).
-   Incluye: descripción clara, pasos para reproducir, impacto y, si es posible, PoC. Evita adjuntar datos sensibles.

## 🔒 Alcance

-   Código del repo (backend, frontend, scripts, docs).
-   Configuración de seguridad (JWT/CSRF, rate limiting, headers, sanitización).
-   Integraciones (Supabase, Redis, FFmpeg, OCR, Whisper) en la medida aplicable al código aquí.

## 🛑 Fuera de alcance

-   Claves/servicios **externos** del equipo (si ves credenciales expuestas, avisa por correo para rotarlas).
-   Ataques de denegación de servicio a entornos no administrados por la comunidad.

## 🔁 Confirmación

Haremos lo posible por responder en **7–14 días** y, si aplica, dar seguimiento con un fix o mitigación. Este es un proyecto **de portafolio**; la corrección puede priorizarse según impacto.

## 🧾 Versiones

-   Rama `main`: estado **MVP** (en desarrollo).
-   Release **v0.1.0**: primera publicación pública.

Gracias por la divulgación responsable 🙏
